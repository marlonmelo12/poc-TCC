# docs/experimentos

Documentação operacional para execução dos experimentos do TCC.

## Ordem
`00` → fonte de verdade  
`01` → questões/bloqueios  
`02` → protocolo  
`03` → QUBO  
`04` → ML/HPO  
`05` → leakage  
`06` → validação  
`07` → execução  
`08` → decisões  
`09` → auditoria final

## Regra principal
O agente deve consultar estes arquivos antes de alterar metodologia ou iniciar experimento.

Uma decisão não especificada deve ser registrada antes de ser incorporada ao protocolo.
